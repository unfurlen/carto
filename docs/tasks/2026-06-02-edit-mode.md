# Edit mode

## Acceptance criteria

```
AC #1: A pencil icon (✏️) is displayed at the top right of the grid.
AC #2: Clicking the pencil switches to edit mode — URL adds edit=true.
AC #3: Loading a URL with edit=true renders the grid with a different background colour and a highlighted pencil.
AC #4: Clicking the highlighted pencil switches back to play mode — edit param removed from URL.
AC #5: Loading a URL with edit=false (or any value other than true) renders the grid in play mode (no highlighted pencil, default background).
```

## Design notes

- URL param `edit=true` toggles edit mode. Absence of param or any value other than `true` defaults to play mode.
- Same ✏️ icon for both modes — visual distinction via styling (highlighted vs default).
- Placement: top right of the grid.

# Visited tiles show green background

## Acceptance criteria

```
AC #1: Given a game with no moves, when rendered, the player's starting tile has a green background.
AC #2: Given a game where the player has moved, when rendered, all tiles the player has occupied have a green background.
AC #3: Given a game where the player has moved, when rendered, a tile the player has never occupied does not have a green background.
```

# carto

## Goals

1. **Build a fun puzzle game** — a game that's enjoyable to play.
2. **Make it something fun to maintain long term** — code quality, joy in refactoring, and sustainable pace.
3. **Try an approach to URL-encoded state** — encode game/app state in the URL for shareability and deep linking.
4. **Develop an effective AI workflow** — build specialized AI personas (TDD test writer, TDD code writer, TDD refactorer, workflow reviewer, etc.) that assist in the development process.

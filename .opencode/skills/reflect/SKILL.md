## What I do

- Summarise what happened during the task — key decisions, friction points, outcomes
- Review any open experiments in `docs/experiments/` — for successful ones, convert them to decisions in `docs/decisions/`
- Suggest process improvements outside of the code — workflow, tooling, communication, skill gaps

## When to use me

Use this at the end of a task cycle, after code changes are done. The AI produces a retrospective — implementation and next-task planning are separate steps.

## Constraints

- Do not propose code changes — only process improvements
- Do not plan or scope the next task
- If nothing meaningful to improve, say so
